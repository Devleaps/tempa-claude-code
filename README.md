# Tempa for Claude Code

The Tempa plugin for Claude Code, with the `tempa` CLI inside (`bin/tempa.mjs`).

```sh
claude plugin marketplace add Devleaps/tempa-claude-code
claude plugin install tempa@devleaps
```

Then run `/tempa:login` in Claude Code.

This repository is release output: every Tempa release replaces its contents in one commit. Do not edit it
or open pull requests here.
